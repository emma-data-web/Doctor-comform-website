# Book & Event Ticket system

A FastAPI backend for buying books and event tickets online.

## Features

- User authentication
- Browse and purchase books
- Browse and purchase event tickets
- Secure payments with Stripe
- Order management
- Event management
- Book management
- PostgreSQL database
- API documentation with Swagger

## Tech Stack

- FastAPI
- Python
- SQLAlchemy
- PostgreSQL
- Pydantic
- Stripe
- Alembic
  

## Getting Started

uvicorn app.main:app --reload
